# About Me

Hi! I'm **Kfir Gisman**, a Backend Software Engineer and Cybersecurity Researcher focused on building, securing, and scaling production-grade systems.

Recognized as a **Top 8 Global FastAPI Expert (2025)**, I specialize in high-performance Python backends (`asyncio`, concurrency, memory optimization) and cloud security. My experience spans fast-paced tech startups—including **Spectral** through its acquisition by **Check Point**—as well as mission-critical, large-scale public sector initiatives at **Treelogic / INCIBE**.

Whether it's optimizing API latency by up to 80%, architecting distributed async pipelines with RabbitMQ and Celery, or building security guardrails for AI/LLM workflows, I focus on turning complex technical requirements into fast, resilient software.

Beyond day-to-day engineering, I actively create technical content on Medium and Dev.to, host the *Code with Mate* podcast, present at DevSecOps meetups, and contribute to open-source software.
